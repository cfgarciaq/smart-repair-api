<a name="castellano"></a>
## 🇪🇸 Castellano

Sistema de gestión técnica de alto rendimiento diseñado para el seguimiento de reparaciones en tiempo real, optimización de costes y gestión del ciclo de vida del cliente.

### Características
- **ASP.NET Core 8**: API REST moderna y multiplataforma.
- **PostgreSQL & Supabase**: Almacenamiento robusto con seguridad RLS.
- **Búsqueda Avanzada**: Filtrado no sensible a mayúsculas por dispositivo, cliente y técnico.
- **Infraestructura Dinámica**: Control de CORS y paginación vía variables de entorno.

### Guía de Configuración
1. **Clonar** el repositorio.
2. **Configurar** variables: `ConnectionStrings__DefaultConnection` y `ALLOWED_ORIGINS`.
3. **Migraciones**: `dotnet ef database update`.
4. **Ejecutar**: `dotnet run`.
